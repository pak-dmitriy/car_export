# Car Export — Backend

REST API сайта-каталога подержанных автомобилей из Кореи на экспорт в страны СНГ: каталог, админка, сообщения между покупателем и менеджером.

**Стек:** Java 25, Spring Boot 4, Spring Security (JWT), Spring Data JPA, PostgreSQL, Flyway, Swagger (springdoc), Cloudinary, Docker.

**Демо:**

- Сайт: [car-export-kor.vercel.app](https://car-export-kor.vercel.app)
- Swagger: [car-export-api.onrender.com/swagger-ui.html](https://car-export-api.onrender.com/swagger-ui.html)
- Фронтенд: [car_export_frontend](https://github.com/pak-dmitriy/car_export_frontend)

Демо работает на бесплатных тарифах: после простоя первый запрос может идти около минуты, пока сервер просыпается.

____

## Что нужно установить

Maven устанавливать не нужно, используется встроенный `./mvnw`.

## Быстрый старт

### 1. Поднять базу данных

PostgreSQL запускается в Docker из файла `docker-compose.yml` в корне проекта:

```bash
docker compose up -d
```

| Параметр | Значение |
|---|---|
| Хост и порт | `localhost:5434` |
| База | `carexportdb` |
| Пользователь | `postgres` |
| Пароль | `root` |

**Остановить базу:** `docker compose down`.

**Остановить и удалить все данные:** `docker compose down -v`.

### 2. Задать переменные окружения

Для локального запуска почти всё уже настроено по умолчанию: подключение к базе из шага 1, тестовый секрет JWT, порт 8081 и адрес фронтенда `http://localhost:5173`. Обязательно задать нужно только почту и пароль администратора, иначе в базе не будет ни одного админа:

| Переменная | Описание |
|---|---|
| `ADMIN_EMAIL` | почта администратора, создаётся при старте |
| `ADMIN_PASSWORD` | пароль администратора, минимум 8 символов |

```bash
export ADMIN_EMAIL=admin@example.com
export ADMIN_PASSWORD=your-strong-password
```

В IntelliJ IDEA эти же переменные добавляются в Run Configuration: поле Environment variables, кнопка с иконкой списка, затем `+` для каждой переменной (в однострочном поле их можно перечислить через точку с запятой).

Остальные переменные нужны, если вы хотите изменить настройки по умолчанию:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DB_URL` | `jdbc:postgresql://localhost:5434/carexportdb` | адрес базы данных |
| `DB_USERNAME` | `postgres` | пользователь БД |
| `DB_PASSWORD` | `root` | пароль БД |
| `JWT_SECRET` | тестовый ключ для разработки | ключ подписи токенов, в продакшене задайте свой длинный секрет |
| `CORS_ORIGINS` | `http://localhost:5173,http://localhost:3000` | адреса фронтенда через запятую |
| `PORT` | `8081` | порт приложения |
| `DEMO_BUYER_EMAIL` | пусто | почта тестового покупателя (необязательно) |
| `DEMO_BUYER_PASSWORD` | пусто | пароль тестового покупателя, минимум 8 символов |
| `CLOUDINARY_CLOUD_NAME` | пусто | имя аккаунта Cloudinary |
| `CLOUDINARY_API_KEY` | пусто | ключ Cloudinary |
| `CLOUDINARY_API_SECRET` | пусто | секрет Cloudinary |

Администратор и покупатель создаются только если заданы и почта, и пароль. Если пользователь с такой почтой уже есть, пароль не меняется.

Без переменных Cloudinary приложение работает, но загрузка фото возвращает ошибку 503.

### 3. Запустить приложение

```bash
./mvnw spring-boot:run
```

Приложение стартует на `http://localhost:8081`.

Фронтенд запускается отдельно, инструкция в его репозитории.

## Миграции базы данных

Схемой БД управляет **Flyway**. Отдельных команд запускать не нужно: все миграции применяются автоматически при старте приложения.

- Файлы лежат в `src/main/resources/db/migration`, имена вида `V<номер>__<описание>.sql`.
- Flyway выполняет их по порядку номеров и записывает применённые версии в таблицу `flyway_schema_history`.
- Уже применённые миграции нельзя редактировать. Для любого изменения схемы создаётся новый файл со следующим номером.
- Hibernate только проверяет, что схема совпадает с сущностями (`ddl-auto: validate`), и ничего не создаёт сам.
- Чтобы начать с чистой базы, удалите данные (см. раздел «1. Поднять базу данных») и запустите приложение заново: все миграции применятся с нуля.

## Swagger

После запуска документация API доступна без авторизации:

- [Swagger UI](http://localhost:8081/swagger-ui.html)
- [OpenAPI JSON](http://localhost:8081/v3/api-docs)

**Как вызывать защищённые методы:**

1. Выполните `POST /api/auth/login` и скопируйте значение поля `token` (без кавычек) из ответа.
2. Нажмите кнопку **Authorize** в правом верхнем углу Swagger UI.
3. Вставьте токен и подтвердите.

## Роли и доступ

В системе две роли: `USER` и `ADMIN`.

| Роль | Что может |
|---|---|
| Гость | смотреть каталог и страницу машины, регистрироваться, входить |
| `USER` (покупатель) | всё, что гость, плюс профиль и сообщения: задать вопрос по машине, читать и дополнять свои переписки |
| `ADMIN` | всё, что покупатель, плюс управление машинами, фото, статусами, пользователями, дашборд, ответы на любые переписки и их закрытие |

Пользователя со статусом `BLOCKED` система не пускает. Чужие переписки недоступны: сервер возвращает 403.

## Статусы машин

| Статус | Значение | Виден в каталоге |
|---|---|---|
| `DRAFT` | черновик | нет |
| `PUBLISHED` | в наличии | да |
| `RESERVED` | зарезервирована | да |
| `SOLD` | продана, изменить нельзя | нет |
| `HIDDEN` | скрыта | нет |

Переходы между статусами ограничены правилами: например, из `DRAFT` можно перейти только в `PUBLISHED` или `HIDDEN`, а из `SOLD` дальше нельзя.

## Основные эндпоинты

| Метод | Путь | Доступ |
|---|---|---|
| POST | `/api/auth/register`, `/api/auth/login` | все |
| GET | `/api/cars`, `/api/cars/{id}` | все |
| GET, PUT | `/api/users/me` | вошедший пользователь |
| POST, GET | `/api/messages/threads` | вошедший пользователь |
| GET | `/api/messages/threads/{id}` | участник переписки или админ |
| POST | `/api/messages/threads/{id}/messages` | участник переписки или админ |
| PATCH | `/api/messages/threads/{id}/close` | админ |
| GET, POST, PUT, DELETE | `/api/admin/cars` | админ |
| PATCH | `/api/admin/cars/{id}/status` | админ |
| POST, PATCH, DELETE | `/api/admin/cars/{carId}/images` | админ |
| GET, PATCH | `/api/admin/users` | админ |
| GET | `/api/admin/dashboard` | админ |

Полный список с примерами запросов смотрите в Swagger.

## Фото

Фото машин загружаются в Cloudinary (до 10 на машину, JPG, PNG или WEBP, до 5 МБ), в базе хранится ссылка. Диск бесплатного хостинга не постоянный, поэтому хранить файлы на самом сервере нельзя.

## Деплой

| Часть | Сервис |
|---|---|
| Бэкенд | Render (Docker) |
| База данных | Neon (PostgreSQL) |
| Фото | Cloudinary |
| Фронтенд | Vercel |

Сборка Docker-образа:

```bash
docker build -t car-export-api .
```

На Render используется этот же `Dockerfile`. Все переменные из раздела «2. Задать переменные окружения» задаются в настройках сервиса. Для бесплатного тарифа (512 МБ памяти) дополнительно задана переменная `JAVA_TOOL_OPTIONS=-XX:MaxRAMPercentage=65 -XX:+UseSerialGC`.
